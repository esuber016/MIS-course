# 校園設備報修系統

使用者可建立報修案件，管理人員可查看案件、更新處理狀態，並依案件編號或緊急程度排序。
本次功能主題為「管理後台案件排序」，協助管理人員快速查看最新案件與安排維修順序。

## 系統需求

- Windows 10/11
- Python 3.13.x（本專案原有教學環境）
- Edge 或 Chrome 瀏覽器
- Python 套件依 `requirements.txt` 安裝（Flask 3.1.3）

## 啟動方式

在本專案資料夾開啟 PowerShell，第一次使用時執行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

之後啟動只需執行：

```powershell
.\.venv\Scripts\python.exe app.py
```

啟動後，以瀏覽器開啟：

- 報修頁面：<http://127.0.0.1:5000/>
- 管理後台：<http://127.0.0.1:5000/admin>

在 PowerShell 按 `Ctrl + C` 可停止伺服器。

## 操作方式

1. 在報修頁面填寫地點、設備、問題描述、緊急程度與聯絡方式，建立案件。
2. 開啟管理後台，查看案件清單與緊急程度。
3. 使用排序選單切換案件順序。
4. 如需更新處理狀態，選擇狀態後按「儲存狀態」。
5. 按清單中的「重新整理」，可重新取得案件資料。

### 排序規則

| 排序方式 | 規則 |
| --- | --- |
| 編號大到小（預設） | 去除 `T-` 後，依數字由大到小排列 |
| 編號小到大 | 去除 `T-` 後，依數字由小到大排列 |
| 緊急程度高到低 | 緊急 → 急件 → 一般 |
| 緊急程度低到高 | 一般 → 急件 → 緊急 |

依緊急程度排序時，同級案件一律依編號小到大排列。

清單重新整理或儲存狀態後，沿用目前排序；整個網頁重新載入後，恢復預設排序。

## 專案結構

```text
app.py                  Flask 後端、案件 API 與記憶體資料
requirements.txt        Python 套件清單
templates/index.html    報修頁面
templates/admin.html    管理後台頁面
static/app.js           報修表單互動
static/admin.js         案件載入、排序、顯示與狀態更新
static/style.css        頁面樣式與響應式排列
software-spec.md        功能規格
AGENTS.md               Agent 通用工作規則
SKILL.md                排序功能檢查流程
README.md               專案使用說明
```

既有 API 包含：

- `GET /api/tickets`：取得案件清單。
- `POST /api/tickets`：建立報修案件。
- `PATCH /api/tickets/<ticket_id>`：更新案件狀態。

## Agent 工作與檢查流程

1. 閱讀 `AGENTS.md`、本次任務使用的 `SKILL.md` 與 `software-spec.md`。
2. 檢查相關程式及資料流程，簡短說明修改範圍與驗證方法。
3. 依規格進行必要修改，保留使用者既有修改，避免無關重構。
4. 對照規格的完成條件執行測試或手動檢查。
5. 依 SKILL 的格式回報結果，包含對應規格、受影響範圍、測試操作、預期與實際結果，以及需要人工確認的事項。

排序功能的檢查重點：

- 四種排序與預設排序正確，編號依數字比較。
- 緊急程度相同時，依編號小到大排列。
- 切換排序立即更新畫面，不額外呼叫 API。
- 清單更新或儲存狀態後保留排序，整頁重載後恢復預設。
- 空清單顯示提示，切換排序不發生錯誤。
- 小螢幕控制項能換行。

檢查結果使用「通過／需要修改／需要人工確認」；未執行的測試不得標示為通過。本 README 列出檢查方式，不代表所有項目已通過實測。

## 範圍與已知限制

- 本次需求僅調整管理後台排序與欄位顯示，不新增搜尋或篩選。
- 排序在前端處理，沿用既有 API，不變更後端資料。
- 排序偏好不跨整頁重新載入保留。
- 切換排序會重建表格，尚未儲存的狀態選擇會重設，請先儲存再排序。
- 案件資料僅暫存在 Python 記憶體中，停止或重啟程式後會清空。
- 本專案以 Flask 除錯模式啟動，供本機課堂示範使用。
