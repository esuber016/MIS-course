# 校園設備報修系統：案件排序功能簡易規格書

## 系統目標

讓管理人員可以依案件編號或緊急程度排序報修案件，快速查看最新案件與安排優先維修順序。

## 使用者

- 校園設備報修管理員：查看案件、切換排序方式與更新案件狀態。
- 維修安排人員：依緊急程度查看案件，安排維修順序。

## 核心功能

### FR-01 選擇排序方式

管理後台提供四種排序選項：編號大到小、編號小到大、緊急程度高到低、緊急程度低到高。預設為編號大到小。

### FR-02 案件比較規則

案件編號去除 `T-` 後，依數字大小比較。緊急程度由高到低為「緊急、急件、一般」，由低到高則相反；緊急程度相同時，依編號小到大排列。

### FR-03 即時排序與保留選項

切換排序選項後，立即更新案件清單。重新整理清單或儲存案件狀態後，沿用目前排序；整個網頁重新載入後，恢復預設排序。

### FR-04 顯示緊急程度與空清單提示

管理後台的案件表格顯示緊急程度。沒有案件時顯示提示，切換排序不應發生錯誤；小螢幕上的控制項可以換行顯示。

## 限制與規則

- 僅調整管理後台的排序與欄位顯示，不新增搜尋或篩選功能。
- 沿用既有 `GET /api/tickets` 取得案件，不變更後端資料。
- 排序在前端處理，切換選項時不另外呼叫 API。
- 排序偏好不跨整頁重新載入保留。
- 切換排序會重建表格，尚未儲存的狀態選擇會重設，應先儲存再排序。

## 完成條件

- 開啟管理後台時，能看到排序選單與緊急程度欄位，預設依編號大到小排列。
- 兩種編號排序皆依數字正確排列。
- 兩種緊急程度排序皆符合規則，同級案件依編號小到大排列。
- 重新整理清單或儲存案件狀態後，仍保留目前排序。
- 整頁重新載入後，恢復預設排序。
- 空清單顯示提示，且切換排序不發生錯誤。
- 小螢幕上的控制項能換行顯示。
