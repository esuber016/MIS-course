# 案件排序功能檢查 Skill

## 使用時機

當任務涉及以下內容時使用本 Skill：

- 修改案件排序方式或比較規則
- 修改緊急程度欄位或預設排序
- 檢查排序保留、空清單及響應式版面
- 設計或執行相關測試

## 執行流程

1. 讀取 `software-spec.md`，確認相關需求與限制。
2. 檢查受影響的畫面、程式及 API。
3. 確認案件編號、緊急程度及同級案件的排序規則。
4. 檢查排序切換、狀態儲存、重新載入與空清單情況。
5. 對照完成條件，整理測試結果與待確認事項。

## 不可忽略的事項

- 預設依案件編號大到小排序。
- 案件編號去除 T- 後依數字比較。
- 緊急程度依「緊急、急件、一般」排序，同級時依編號小到大排列。
- 排序在前端處理，不額外呼叫 API。
- 清單更新或儲存狀態後保留排序，整頁重新載入後恢復預設值。
- 不新增規格未要求的功能，不修改無關程式。
- 不得將未執行的測試標示為通過。
